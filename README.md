# Vivek's Portfolio

A modern, responsive portfolio website with 3D animations and particle effects.

## Features

- **3D Particle Background** - Interactive particle system with connections
- **Custom Cursor** - Smooth cursor following effect
- **Typing Animation** - Dynamic text typing in hero section
- **Smooth Scrolling** - Seamless navigation between sections
- **Responsive Design** - Works on all devices
- **3D Card Effects** - Interactive project cards with perspective
- **Animated Skills** - Progress bars with smooth animations
- **Contact Form** - Working contact form with validation

## Sections

1. **Hero** - Introduction with 3D particle background
2. **About** - Personal information and stats
3. **Skills** - Technical skills with progress bars
4. **Projects** - Portfolio projects with filtering
5. **Contact** - Contact form and social links

## Technologies Used

- HTML5
- CSS3 (with 3D transforms and animations)
- JavaScript (ES6+)
- Canvas API (for particle effects)

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/vivek0707/portfolio.git
   ```

2. Open `index.html` in your browser

## Customization

- Edit `index.html` to change content
- Modify `style.css` to change colors and styles
- Update `script.js` to change animations
